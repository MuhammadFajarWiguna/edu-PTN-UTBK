## 📝 Cara Login

1. Buka website → Klik **"Masuk"**
2. Masukkan email & password dari daftar di atas
3. Klik **"Masuk ke Dashboard"**
4. ✅ Done!

---

## ➕ Register Akun Baru

1. Klik **"Daftar gratis"**
2. Isi formulir:
   - **Nama Lengkap**: Nama kamu
   - **Email**: email@example.com
   - **Password**: minimal 6 karakter
   - **Konfirmasi Password**: ulangi password
3. Klik **"Buat Akun Sekarang"**
4. Akan muncul pesan sukses
5. Login dengan akun baru kamu

**Tips:** 
- Email mengandung "admin" → otomatis role ADMIN
- Email biasa → role SISWA

## 🐛 Troubleshooting

### Login gagal?
- Pastikan email & password benar (case-sensitive)
- Coba demo account dulu: `demo.siswa@eduptn.com` / `demo123456`
- Check console browser (F12) untuk error

### Lupa password?
- Untuk demo accounts: lihat list di atas
- Untuk akun registrasi: clear browser data → register ulang

### Session hilang setelah refresh?
- Pastikan browser tidak dalam mode incognito
- Check browser settings: allow cookies & localStorage
